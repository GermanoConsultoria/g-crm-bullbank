# BullBank CRM

Crie um crm, minimalista, no tema escuro, com cores azul, branco e cinza

Deve conter cadastros de clientes, quadro kanban editaveis de etapas do funil de vendas, com tarefas para serem criadas acompanhando a produtividade do vendedor, relatorios para analise de maior conversão por tipo de lead, dashboard , calculo de comissão...
